# Calculadora de IMC

O conceito é simples: você informa seu nome, peso e altura. 
O site calcula seu IMC usando a fórmula peso dividido pela 
altura ao quadrado. Dependendo do resultado ele te classifica 
em 4 categorias: Magrelo, Peso Normal, Sobrepeso ou Obesidade, 
cada uma com mensagens aleatórias e bem-humoradas que mudam 
a cada cálculo. Nada de resultado chato e sem graça.
